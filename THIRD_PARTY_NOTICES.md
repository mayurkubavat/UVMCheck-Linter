## Derived data

[`data/uvm-api/`](data/uvm-api/) holds tables of UVM class and method names,
signatures and deprecation status, generated by
[tools/codegen/gen_uvm_api_pack.py](tools/codegen/gen_uvm_api_pack.py) from
the Accellera UVM library ([uvm-core](https://github.com/accellera-official/uvm-core),
Apache License 2.0, Copyright Accellera Systems Initiative and contributors).
No UVM source code is copied. The tests and CI fetch uvm-core at run time;
it is not part of this repository.

## Test fixtures

Files under [`testdata/`](testdata/) were written for this project. The UVM
stub in `testdata/common/` declares a small subset of the IEEE 1800.2 API so
the rule tests compile without the real library; it contains no Accellera
code.
